# Aula Adaptativa

Plataforma educativa en desarrollo para apoyar el aprendizaje de matemáticas en estudiantes de secundaria en México. El primer tema que abordaremos son las ecuaciones lineales.

## Estado del proyecto

Prototipo inicial. El diseño de la interfaz se está preparando en Figma.

## Tecnologías

- React
- Vite
- JavaScript

## Ejecutar el proyecto localmente

Necesitas tener Node.js y npm instalados. Desde la carpeta del proyecto, ejecuta:

```bash
npm install
npm run dev
